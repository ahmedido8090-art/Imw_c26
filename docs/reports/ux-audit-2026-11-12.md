# UX audit: GEM Navigator (whole app)

2026-11-12 · iPhone 17 simulator, iOS 26.1 (light, dark, English, Arabic) ·
debug build via `flutter test integration_test/ux_walkthrough_test.dart -d <sim>`
with host-side `xcrun simctl io … screenshot` at every step.

Toolchain notes (not UI): the iOS deployment target was raised 13.0 → 15.0
because this Xcode refuses to build below 15.0; `flutter build ios --simulator`
(fat binary) fails on this Xcode's `lipo -verify_arch`, so the app was run
per-device (`flutter run -d` / `flutter test -d`), which builds arm64 only.

Baseline: `flutter analyze` 15 infos (deprecations, 0 warnings/errors);
`flutter test` 46/46 passing.

## Product model

- **What / who:** an offline indoor map of the Grand Egyptian Museum for
  visitors on site, in eight languages. No GPS: the visitor says where they are.
- **Primary goal:** find a place (search or map) → get walking directions.
- **Core:** map screen (4 plans), search, place sheet, "Where are you?",
  route card + directions. **Secondary:** My tour (pins), settings.
  **Tertiary:** stories, about, era timeline.
- **Most frequent actions:** search → place → Start route; switching plans;
  setting the start point. These get the most polish.

## Consistency / microcopy

## Accessibility

| # | Issue | Fix | P |
|---|---|---|---|
| A1 | Plan tabs are a bare `GestureDetector`: VoiceOver sees no button and no selected state | `Semantics(button, selected)` + InkWell | P1 |
| A2 | Category and era chips expose no selected state; the tour badge count is not announced | Semantics on the shared chip; badge in the tooltip label | P2 |
| A3 | Fixed heights (search pill 46, chips 40/38, entrance card name box 34) clip at large Dynamic Type | Let heights grow (min height instead of fixed) where text sits | P2 |
| A4 | The beacon/route loop runs forever while a location is set and ignores Reduce Motion | Stop the loop when `MediaQuery.disableAnimations` is on | P2 |

## Design system

Colours are already tokenised (`GemPalette`), so no palette change is needed. Gaps:
- **Type:** 18 distinct font sizes (9.5 to 24), set inline in every widget.
  Proposed scale: 12 caption · 14 body/label · 16 row title · 22 sheet title
  (+ 12 caps eyebrow). Applied to shared components and the screens touched.
- Radii 16/18/20/22/23/24/26/28: left as is except where components are merged (C3).

## Motion

| # | Moment | Problem | Fix | P |
|---|---|---|---|---|
| M1 | Pin toggle | Sheet slides out and back in | In-place toggle (F3) | P1 |
| M2 | Perpetual beacon pulse | Ignores Reduce Motion | A4 | P2 |

Transitions elsewhere (search fade-rise 260ms, AnimatedSize on route card,
toast slide) are short and consistent; no change.

## Needs a product decision

- **Era chips (F4):** (a) restore highlighting of the era's galleries on the
  plan, (b) keep as information only and restyle them as a legend, or
  (c) remove. Recommendation: (a) if the canvas still supports `highlighted`,
  otherwise (b).
- **Rostau entry point and relation to "My tour"** (asked separately).

## Not changed on purpose

- The plan artwork, pins and labels on the canvas (generated/traced data).
- Palette, fonts (Georgia + Arial), sheet style: they are the product's language.

# Second pass (after fixes) — 2026-11-12

Decisions taken with the product owner: implement all P1–P3; era chips
**highlight** their galleries; the button under "−" becomes **My tour**, the
top-end button becomes **Rostau trips** (icon: Gardiner N31 *wꜣt*, "road");
own trips via an **editor + "Save as trip"** from the pinned tour.

## Second-pass findings

All fixed above except: distances above 1 km read in metres ("2570 m"); left
as is (walks stay under ~3 km and the formatter rounds on purpose). The plans
are width-limited in portrait and fill about half the screen; "Turn map 90°"
exists in Settings. Auto-rotating is a product call, not changed.

## Result

- Issues found: 22 (first pass) + 4 (second pass). Fixed: 25. Left by decision: 1 (km formatting).
- Device: iPhone 17 simulator, iOS 26.1, light/dark, en/ar/de, default and
  *accessibility-large* text. `integration_test/ux_walkthrough_test.dart`
  passes end to end (5 journeys, 41 screenshots). SharedPreferences is mocked
  in that test, so persistence was checked through the app's `Store`
  (relaunch test), not the device's on-disk preferences.
- `flutter analyze`: 15 infos, identical to the baseline (pre-existing deprecations).
- `flutter test`: 51/51 (46 baseline + 4 Rostau UI + 1 Reduce Motion).
- Not verified: VoiceOver reading the new semantics; Reduce Motion on the device
  (the headless simulator ignored the setting even after a reboot); Android;
  tablets and small phones; real hardware.
- Toolchain: iOS deployment target 13.0 → 15.0 (this Xcode refuses lower);
  `integration_test` (Flutter SDK) added as a dev dependency.
